开始使用
1. 解压整个文件夹，不要从 ZIP 内直接打开网页。
2. 电脑需要已有 Node.js（20 或以上）和现代浏览器。运行不需要联网。
3. Windows 双击 Start.cmd，保留启动窗口。
4. 浏览器打开 http://127.0.0.1:4174 。若预览已运行，直接打开此地址。
5. 关闭启动窗口会停止本地预览。
Directly opening index.html is only a visual preview. Use the local server so
subpages share browser storage. Node.js is not bundled.
On macOS/Linux, run: node server.cjs

LIVE PRESENTATION
Follow the four parts: where we are; evidence and commitment; working product;
next steps. Back up if needed, then reset only the care demonstration.
Start on Free. Record a new care outcome, show the report gate, simulate
Plus failure then success, and download a report containing the new note.
If a live step fails, state the failure and show the labelled recorded example.
Rehearse with a stopwatch. Stop by seven minutes; questions come afterwards.
The proposed 90-day closure plan starts after the course ends: archive and remain
inactive unless the team explicitly reopens the project with suitable evidence.

DATA AND BOUNDARIES
All care records and the demo clock are fictional. Enter no real health data.
The original two-phone example and working household have separate histories.
Data stays in this browser and origin; other ports and browsers differ.
Demo tools can export a backup. Restoring replaces all workspace state,
including outreach and unsent requests, after confirmation. Resetting care
preserves outreach records and unsent evaluation requests.
Payments and AI are simulations. There are no connected accounts, live
notifications, emergency response or live AI model. AI uses local templates.
Generated download filenames contain a UTC export timestamp. The report was
saved and compared with its preview on 20 September 2026. Period activity and
all-date open work are distinct; old unresolved work remains in reports.
Browser settings may affect saving. The example report is fictional.
Financial inputs are assumptions. Actual development and service costs are
unmeasured. Functional checks do not establish commercial or clinical viability.

Reproduce the twelve experiments against the included source snapshot:
  node evidence/run-functional-experiments.cjs
