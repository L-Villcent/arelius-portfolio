# Sliver Care 网站使用与讲解指南

适用版本：Group6 本地MVP与实际邀约记录版（2026年9月22日）。

本网站把展示、产品操作、商业分析和课程材料分开。首页的双手机是教学示例；真正保存照护记录、切换套餐并生成报告的是 Care workspace。两者记录不互通。

## 一 开始使用

1. 解压完整交付包。电脑需要 Node.js 20 或以上及现代浏览器。
2. Windows 双击 Start.cmd，保留启动窗口。macOS/Linux 可在产品文件夹运行 node server.cjs。
3. 打开 http://127.0.0.1:4174 。已有预览运行时可直接使用，不必重复启动。
4. 课堂前在同一台电脑、同一浏览器和同一地址排练。工作台数据保存在该浏览器中，换浏览器或端口不会自动同步。
5. 演示前可在 Care workspace → Demo tools 下载完整备份。准备新演示时只重置照护场景。完整备份恢复会替换整个工作台数据。

## 二 八个页面分别做什么

| 页面与入口 | 如何使用 | 讲解重点 |
| --- | --- | --- |
| Product / index.html | 运行双手机中的确认、未响应和求助场景。查看Free、Plus、Pro，切换月付/年付及5x/20x，阅读权益比较。 | 为什么“提醒之后谁跟进、结果如何记录”有价值；三档各适合什么家庭。 |
| Care workspace / workspace.html | 建立家庭角色、安排提醒、记录回应及跟进，模拟订阅成功/失败，再生成照护报告；Pro可演示值班、备用人与交接。 | 现场证明产品可操作。重点展示新输入的结果确实进入导出的报告。 |
| Customer offer / offer.html | 阅读面向家庭的报价与邀约，展开机构版本，下载邀请文本；本地评估表单可保存草稿。 | 对谁销售、报价多少、让对方先做什么，以及如何进入下一步。表单不会自动发出邀请。 |
| Business model / business.html | 看谁付费、为何付费、可能的渠道和商业画布；调整付费家庭数、成本、流失等参数后点击 Recalculate。 | 收费如何覆盖成本，哪些假设最影响结果。所有参数都是模型输入，不是财务实绩。 |
| Customer outreach / outreach.html | 查看8位个人咨询、10家机构邮件；展开P01–P08及O01–O10，查看反馈、日期和来源，下载CSV或JSON。 | 展示实际咨询与邀约；截图为代表性节选。机构尚未回复，个人反馈不等于购买承诺。 |
| Classroom kit / presentation.html | 下载PPT、学术版PDF、LaTeX源文件、Word内容副本、讲稿和本指南；展开讲者备注，按0:00–6:30路线排练。 | 组织七分钟课堂展示，确保四部分顺序正确，给转场留30秒。 |
| Report / report.html | 从Classroom kit点击 Read the report。查看Group6名单、Stop决定、八部分正文、截图和声明索引，下载报告。 | 供老师阅读正式报告。它是课程报告，不是工作台生成的家庭照护报告。 |
| Evidence library / evidence.html | 从Classroom kit或Report进入。打开每条来源、记录、原始输出和可复现实验；通过Claim register回到声明索引。 | 回答“这个结论依据什么”。区分实际邀约记录、模型输入和实际运行的产品实验。 |

Customer outreach采用实际咨询与邀约记录。2026年9月20日至22日咨询8位个人；9月20日向10家机构发送含MVP演示视频和产品介绍PDF的邮件，截至9月22日未收到机构回复。4份聊天截图与1张邮件列表截图为控制篇幅而选取的代表性展示，并非全部记录。 旧课堂模拟记录单独归档，不计入这18个对象。

## 三 工作台里的七个栏目

| 栏目 | 操作 | 展示价值 |
| --- | --- | --- |
| Care desk | 在Reminder plans点Start now；随后点Check in或Request help，再用Record outcome保存跟进结果。未完成事项可添加备注；Pro可Hand over。 | 提醒、责任、行动和结果构成完整流程。 |
| Household | 查看或新增照护对象和家属角色。容量受当前套餐限制。 | 一份家庭套餐如何支持多人协作。 |
| Plans & rota | 新建或编辑提醒、时间及负责人。Pro可设备用人、跟进延迟和值班日期。 | 复杂照护为什么需要Pro。新规则应用于新开始的照护事项。 |
| Reports | 选择照护对象及1/7/30天期间，查看保存记录；Plus或Pro可下载照护报告和原始事件。 | 报告从实际操作生成；历史未完成事项不会因为超过报告周期而消失。 |
| Assistant lab | 选择摘要、交接草稿等用途，运行本地助手并查看剩余额度。 | AI是次级辅助。5x/20x增加额度，Pro照护功能保持相同。 |
| Demo subscription | 选择Monthly demo或Annual demo，检查报价，再选Simulate failure、Cancel或Simulate success。 | 失败不升级、成功开通对应权益、年费总额清楚；不收取真实款项。 |
| Demo tools | 备份、恢复、重置照护场景、推进额度周期。 | 便于排练及保存成果。推进演示时钟和额度周期不代表现实时间或自动续费。 |

## 四 四人课堂演示（本次更新）

目标6:30结束；四人交接为0:50、2:35、5:15。正式展示前6页，后2页仅用于问答。
准备：先备份，Demo tools重置照护场景；再到Demo subscription选择Plus → Monthly demo → Simulate success，收费0；回Care desk。
2:50点Start now；3:10点Request help；3:30点Record outcome；3:45输入Class demo: Alex contacted Margaret and agreed the next step.，点Save & close care item；4:05进入Reports；4:25点Download care report (.txt)，打开下载文件找到相同句子；4:55回PPT第5页；5:15交第四位。
支付失败不在主讲流程。卡住超过10秒切预录并说明不是现场画面；5:15必须进入最后部分。
停止主要原因是团队时间与后续资源安排。未来90天为归档、复盘与保持停止。

## 五 七分钟内讲哪些页面

按演示稿的既定顺序：

- 0:00–0:50：Speaker 1，第1页，产品、客户与本地MVP阶段。
- 0:50–2:35：Speaker 2，第2–3页，问题、原型、MVP及8位个人咨询和10家机构邀约；明确咨询不等于完成试用或购买承诺。
- 2:35–4:55：Speaker 3，第4页介绍任务，然后切到Care workspace演示保存、报告与下载。
- 4:55–5:15：Speaker 3，第5页，演示结论、拟议Plus ¥39/月及通知和同步的局限。
- 5:15–6:30：Speaker 4，第6页，因团队时间与后续资源安排而Stop；90天整理归档、复盘并保持停止，不承诺重新启动。
- 6:30–7:00：转场缓冲。七分钟是硬上限，问答在后。

不用在七分钟内逐页浏览全部网站。Product用于直观介绍和补充演示；Customer offer、Business model、Report及Evidence library适合答疑时打开。PPT中已有价格信息，现场无需再次完整滚动首页。

## 六 可以怎么说

- Product：“我们解决的是提醒发出以后，谁来跟进、最后发生了什么这一段家庭协作。”
- Care workspace：“我现在记录一条跟进结果，随后在导出的报告里找到它。”
- Customer offer：“我们的第一步是一个短时间评估邀请，报价和下一步都写清楚。”
- Business model：“这个模型让我们判断，在给定成本和付费家庭数下，订阅收入是否覆盖支出。”
- Customer outreach：“我们咨询了8位个人并向10家机构发出邀约，机构暂未回复。这里选取部分记录，展示反馈如何影响产品与价格说明。”
- Report：“首页写的是小组真实决定，重要结论在正文，支持材料和声明索引放在附录。”
- Evidence library：“这项产品结论可以回到实验步骤和实际导出文件；咨询和邀约记录采用实际反馈，截图按代表性节选解读。”

## 七 交付与提交

报告为评分主体，首页已列Group6和全部八位成员。报告主版本为学术版PDF（正文8页＋附录17页，共25页），同时提供可编辑LaTeX源文件包。Word保留旧排版，作为内容编辑副本；PPT附讲者备注。由小组确认Blackboard截止日期并仅提交一份报告。课堂可由团队或指定代表讲述；若获准免到课，才适用全员出镜并发言的七分钟视频要求。Quiz不在本次范围内。

## 新增：怎样用场景解释套餐差价

首页套餐下方的 One family. Different care needs. 提供三组可点击的本地示例，每组按1→2→3推进。示例不改变工作台已经保存的记录。

- Plus：Maya接到求助、记录跟进，再打开生成的报告，查看同一条记录。报告导出不耗AI额度。
- Pro 5x：周一由Maya负责、Leo替补；周二把未完成事项交接给Leo，再查看包含责任人和交接备注的报告。
- Pro 20x：先展示100次已用，升级后仍为100次已用但总额升至400；再生成一份交接草稿，显示101次已用、299次剩余。两个Pro的照护功能相同。
- 展开 How monthly AI allowance works：成功生成（包括重新生成）每次计1；失败、取消及无效请求计0；阅读、保存现有草稿和手动导出报告计0。家庭共享额度、不结转，年付仍按月提供；本地周期需要手动推进。
