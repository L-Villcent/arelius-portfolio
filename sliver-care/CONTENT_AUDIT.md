# Sliver Care / Group6 产品内容与作业核查

核查日期：2026年9月20日。范围为八个离线页面、Group6报告（学术版PDF正文8页＋附录17页）、6页演示稿、讲稿及证据包。依据为用户提供的作业截图、期末项目全文要求、已确认套餐和本地实现。附件不是对外联系、收款或提交作业的授权。Quiz已按用户要求排除。

## 核查结论

产品围绕“谁负责跟进、发生了什么、如何保留记录”形成可操作的本地流程。报告首页采用团队真实决定：**Stop，课程结束后暂不推进，保留未来再探索的可能**。现有证据支持本地功能演示，不能支持市场需求、临床收益或商业可行性结论。

报告含30条声明索引、16项可提供的来源和12项有日期、步骤、结果的本地功能实验。自动化检查不冒充用户测试；十个虚构回应不冒充真实访谈、拒绝或承诺。根据用户补充的教师许可，十条记录按正式课程模拟邀约呈现，方法说明和来源保留情境设定。课外真实联系记录另行保存。

## 产品内容一致性

| 主题 | 本版处理及边界 |
| --- | --- |
| 用户与付费人 | 长辈及照护家属为拟议用户，组织照护的成年子女为拟议买方；细分市场待验证 |
| 核心流程 | 提醒、回应或求助、人工跟进、保存结果、报告；双手机示例与工作台历史独立 |
| 状态及责任 | check-in为自我报告，不证明服药；跟进记录不代表临床安全；求助不会自动联系机构、急救或真实家属 |
| Free | 基础提醒、求助、记录及历史可用；额度耗尽不阻断照护，降级保留数据 |
| Plus | 多档案、多计划、负责人及记录报告；报告不需要AI、不耗AI额度 |
| Pro | 跨对象概览、负责人筛选、备用人、时间规则、值班及交接；活动统计不等于依从率 |
| 5x / 20x | 照护权益相同；AI月额度100/400是Plus20的5倍/20倍，不代表模型能力或照护质量 |
| 定价 | Free0；Plus39/月、390/年；Pro5x79/月、790/年；Pro20x99/月、990/年。人民币；离线实际收费0 |
| 年付及容量 | 一次付款总额优先，月均价辅助；额度按月。容量1/1、2/4、5/8明确为离线默认值 |
| 模拟订阅 | 成功才切档，失败/取消不切档，重复订单不重复记账；实际收费恒0 |
| AI | 本地模板，失败/取消不扣额度，切档保留已用量；草稿不自动交接或发送 |
| 报告时间范围 | 活动按期间，待办跨所有日期；旧提醒的新跟进和交接仍进入当前报告 |
| 导出 | 保存的场景报告2329字节、2322字符，与预览一致；文件名附UTC导出时间 |
| 重置及恢复 | 重置照护保留触达与未发邀约；完整恢复替换全部数据，确认文案说明范围 |
| 客户offer | 家庭10分钟免费离线评估、Plus拟议39/390报价与反馈步骤；机构请求反馈或经同意的介绍，没有虚构合作 |
| 表单 | 本地未发送草稿，不表示已联系、预约或取得承诺 |
| 商业模式 | 拟议家庭订阅；渠道待测试，无已有客户、收入、签约伙伴的暗示 |
| 算术 | 默认月ARPU49.47、变动成本18.19、贡献31.27；固定成本30000时平衡点960户，800户时月亏4982.40 |
| 成本局限 | 参数是假设；真实开发工时、服务成本、报价未测量；模型排除启动、税费、融资及增长获客等成本 |
| 日志 | 含对象、日期时间、offer、结果、经历备注，另有渠道、证据位置和下一步；工具不验证实际联系 |
| 视觉 | 竖屏演示先于套餐；移除沿边光点、额外外环、扩散脉冲和Motion开关，保留20x增强与减少动态效果适配 |
