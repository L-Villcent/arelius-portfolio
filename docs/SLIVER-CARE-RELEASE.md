## 如何回溯

1. 查看原网站：在 GitHub 切换到上述备份分支，即可查看完整原始文件。
2. 本地比较：比较该备份分支与 `main`；新功能为单独一次发布提交。
3. 撤销本次接入：在新分支中对本次发布提交执行 `git revert`，审查差异、
   预览验证后合并至生产分支。保留提交历史，不强推或重置 `main`。
4. 后续如果已有其他改动，不要直接还原整个目录；先判断哪些改动需要保留。
5. 需要整站恢复到原版时，从备份分支创建恢复工作分支，与当前生产版比较后
   通过新的恢复提交发布。原网站备份分支本身始终保持不变。
